## Employee Dashboard

The Employee Dashboard is a JavaScript application that loads employee data from a JSON file using the Fetch API.

### Features

- Display employees
- Search employees
- Filter by department
- Sort by name and salary
- View employee details
- Add employee
- Edit employee
- Delete employee

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
- Fetch API

## How to Run

1. Open `employee-dashboard/index.html` in VS Code.
2. Right-click the file.
3. Select **Open with Live Server**.
4. The Employee Dashboard will open in the browser.

## Practical Learning

This project uses modern JavaScript and reusable functions without unnecessary libraries.

The employee data is loaded using `fetch()` and `async/await`. CRUD operations are performed on the data in the browser.

## Note

The current CRUD operations are client-side. Changes are stored only while the page is open and are not permanently written back to the JSON file.
