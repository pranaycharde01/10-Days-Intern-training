# Day 1 - Programming & Problem Solving

## Overview

Day 1 focused on programming fundamentals, problem solving, DSA concepts, and building a command-line application using Java.

## Programming Language

* Java

## Exercises

Solved 15 programming and DSA problems, including:

* Reverse a String
* Palindrome
* Largest Number & Second Largest Number
* Remove Duplicates
* Missing Number & Duplicate Number
* Character Frequency
* First Non-Repeating Character
* Merge Sorted Arrays
* Common Elements
* Stack
* Queue
* Maximum Subarray Sum
* Sorting Without Built-in Sorting
* Two Sum
* Check if Two Strings are Anagrams

## Practical Assignment

### Employee Management CLI

A command-line Employee Management application was developed using Java.

### Features

* Add Employee
* Update Employee
* Delete Employee
* Search Employee
* List Employees
* Find Highest Salary
* Calculate Average Salary
* Filter Employees by Department

## Technologies Used

* Java
* ArrayList
* Scanner
* Basic OOP
* Loops
* Conditional Statements
* Methods

## How to Run

Compile the program:

```bash
javac Employee.java Main.java
```

Run the program:

```bash
java Main
```

## Learning Outcome

Through this assignment, I practiced Java programming, arrays and collections, loops, methods, basic object-oriented programming, problem solving, and command-line application development.
