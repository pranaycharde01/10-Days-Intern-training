# Day 7 - Next.js and Node.js Employee Dashboard

## Objective

To learn Next.js and Node.js with Express by creating a simple Employee Dashboard.

## Technologies Used

- Next.js
- React
- TypeScript
- Node.js
- Express.js
- HTML
- CSS
- JavaScript

## Features

- View all employees
- View employee details
- Add new employee
- Edit employee
- Delete employee
- Employee data validation
- Basic authentication
- Loading and error handling
